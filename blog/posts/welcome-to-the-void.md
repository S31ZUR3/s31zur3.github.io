# Welcome to the void

This is the first post. It exists so the blog isn't empty, and to show the
format every post follows.

## What goes here

Notes from CTFs, techniques worth remembering, and the occasional tool dump.
The goal is the **pattern before the exploit** — the transferable idea, not just
the flag.

- Reverse engineering
- Binary exploitation
- Web, crypto, and forensics
- Tooling and CTF meta

## The format

Every post starts with front matter (title, date, category, tags, summary), then
plain markdown. Code blocks are language-tagged:

```bash
file ./chall
checksec --file=./chall
```

That's it. Delete this post once you've written your own, or keep it as a
reference.
